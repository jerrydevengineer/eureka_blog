3 다음중 컴파일러가 java 코드에 자동으로 처리해 주는 작업이 아닌 것은?

	다른 클래스를 상속하지 않은 클래스에 object 클래스를 상속받도록 한다
	어떤 클래스를 상속받는 클래스의 생성자에 부모 생성자 호출이 없으면 super()를 넣어준다

6 다음 중 예외에 대한 설명 중 올바르지 않은 것은?
	runtime 은 compiler에 의해 체크되지 않는다
	사용자 정의 예외는 runtime 이 아닌 예외만 상속 받아 만들 수 있다 - 
	throw을 이용해서 다양한 객체를 생성하고 호출한 상위 메소드에 그 객체를 전달할 수 있다.
	메소드 선언 부분에 throws nullpointer를 하지 않아도 그 예외가 발생하고 처리하지 않으면 호출한 상위 메소드에 전달 된다
