오늘부터 k8s를 조금씩 공부해보겠습니다. 기본 개념은 관심이 있는 사람이라면 다 알테고 역시 써보면서 배워야 될 거 같아서 일단 바로 설치해봤습니다. 제 컴퓨터는 안 좋아서 못하고 있었는데 컴퓨터 좋은 김에 한 번 해보겠습니다....

일단 먼저 해볼거는 k8s의 장점인 auto-scaling 설정을 해보기 위해 minikube를 설치하고 간단한 웹서버를 띄울겁니다.(아무거도 아님 그냥 apache-php 설정만 되어 있는 겁니다.) php 다신 보고 싶지 않았지만 코드는 안보고 이거만 봐도 화가 살짝 나네요.

우선 minikube를 설치하고 nginx용 yaml 파일을 작성했습니다. 별 건 없고 그냥 최신 이미지랑 2개의 레플리카가 있다는 내용 정도 있고, php-apache 용 yaml에는 오토 스케일링을 위해 CPU 코어의 20% 설정했고, 자동 복구를 위해 확인하는 간격 정도 적용해줬습니다.

일단 오토 스케일링을 하려면 메트릭 서버를 켜줘야 하는데 minikube를 실행시키고 나서
``` bash
minikube addons enable metrics-server
```
해주면 알아서 실행합니다.

그리고 이제 HPA를 실행시켜서 수평 확장하는 기능을 추가해줍니다.
``` bash
kubectl autoscale deployment php-apache --cpu-percent=50 --min=1 --max=10
```

현재 상태 보고 싶으면 이 명령어를 치시면 돼요!
``` bash
kubectl get hpa
```
